NL
    copieer de .fragment files naar de fragments/ folder
    rechts-klik in de folder, klik "Open in Opdrachtprompt", typ ".\fragment_install.exe" en duw op Enter
    de uitkomst kan je vinden in de out/ folder
    voer het programma uit. het kan in een folder staan. haal het niet uit deze folder

EN
    copy the .fragment files to the fragments/ folder
    right-click in the folder, click "Open in Terminal", type ".\fragment_install.exe" and press Enter
    the result can be found in the out/ folder
    run the program. the program can be in a containing folder. do not remove it from the containing folder
